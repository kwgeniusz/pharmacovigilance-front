# Pharmacovigilance Frontend

Vue 3 single-page application for tracing buyers affected by a medication lot and sending individual recall warnings. It integrates with the Laravel Pharmacovigilance API through Sanctum stateful authentication.

## Setup instructions

### Requirements

- NVM
- Node.js 24.19.0 LTS
- npm 12.0.2
- The Laravel API running at `http://localhost:8000`
- Port `5173` available

The repository pins Node in `.nvmrc`. Install and activate it with:

```bash
nvm install
nvm use
```

Install frontend dependencies and create the local environment file:

```bash
npm install
cp .env.example .env
```

Start the Laravel backend from the sibling repository:

```bash
cd ../pharmacovigilance-api
./vendor/bin/sail up -d
./vendor/bin/sail artisan migrate:fresh --seed
```

Start the Vue development server:

```bash
cd ../pharmacovigilance-front
npm run dev
```

Open `http://localhost:5173` and use the seeded credentials:

- Username: `admin`
- Password: `password`
- Affected lot: `951357`

The recall email generated by the alert action can be inspected in Mailpit at `http://localhost:8025`.

## Application routes

| Route | Access | Purpose |
| --- | --- | --- |
| `/pharmacovigilance/login` | Guest | Authenticate pharmacy personnel. |
| `/pharmacovigilance/orders` | Protected | Search medication lots and affected orders. |
| `/pharmacovigilance/orders/:orderId` | Protected | Review an order, buyer, and all medications. |
| `/pharmacovigilance/customers/:customerId` | Protected | Review buyer contact information and order history. |

Unknown paths display a dedicated `404` screen.

## API integration

Set the API origin through:

```dotenv
VITE_API_URL=http://localhost:8000
```

Axios sends credentials and the XSRF header on cross-origin requests. The login sequence is:

1. `GET /sanctum/csrf-cookie`
2. `POST /api/login`
3. `GET /sanctum/csrf-cookie` after Laravel regenerates the session
4. `GET /api/user` when restoring an existing session

A `401` response clears local authentication state and redirects to login. A `419` response refreshes CSRF and retries the original request once. Laravel `422` errors are mapped to form fields or contextual messages.

The search workspace uses the API's actual `lot_number` parameter and synchronizes `lot_number`, `start_date`, `end_date`, and `page` with the URL. It consumes native Laravel Resource responses with `data`, `links`, and `meta`.

## Design decisions

- **Official Vue scaffold:** The project was generated with `create-vue` using TypeScript, Router, Pinia, Vitest, ESLint, and Prettier.
- **Composition API:** Every component uses `<script setup lang="ts">` for concise, typed logic.
- **Small global state:** Pinia owns authentication only. Search state remains in the URL and view so links are reproducible and browser navigation works naturally.
- **Thin API modules:** A shared Axios client manages transport concerns while endpoint modules expose typed domain operations.
- **Stateful Sanctum:** Session cookies keep credentials out of browser storage and match the first-party SPA architecture of the Laravel API.
- **Custom clinical design system:** Native Vue components and CSS tokens provide a focused pharmacy workflow without coupling the interface to a UI framework.
- **Responsive disclosure:** Desktop users receive a dense operational table; small screens receive cards with the same actions and information.
- **Accessible confirmation:** The recall action uses native `<dialog>`, visible focus, meaningful labels, keyboard cancellation, and disabled duplicate submission.
- **No frontend container:** Laravel Sail already provides the required Docker bonus and leaves port `5173` available for the official Vite workflow.

```text
src/
├── api/          # Axios configuration and typed endpoint modules
├── assets/       # Clinical design tokens and responsive styles
├── components/   # Shared layout, search, results, dialog, and pagination
```

## Assumptions

- “Last month” means an inclusive rolling 30-day period.
- Lot `951357` is prefilled to make the seeded evaluation flow immediately testable.
- Buyer alerts are individual because the required API exposes a single-order operation; bulk alerts remain out of scope.
- Email is the only notification channel; SMS, audit storage, roles, and CSV export are bonus features intentionally excluded.
- The backend remains available at `http://localhost:8000`, Vue at `http://localhost:5173`, and Mailpit at `http://localhost:8025`.
- Application content, code, identifiers, tests, and documentation are written in English.
